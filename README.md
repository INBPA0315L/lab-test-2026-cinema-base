# lab-test-2026-cinema-base

Warmup project for lab test 3 of *High-level programming languages 2*: the **cinema** sample sheet, starting state
**base** (no model: you write the model classes from scratch).

* The sheet: [test-3-cinema.md](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/sheets/test-3-cinema.md)
* The tutorial of the model and the repository: [model-cinema.md](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/model-cinema.md)
* The tutorials of the queries: [warmup](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/README.md)
* The complete solution: [solutions/cinema](https://github.com/INBPA0315L/notes-2026/blob/main/warmup/solutions/cinema)

Open the project in IntelliJ IDEA with a JDK 25 environment and the *Lombok* plugin enabled. Do not modify the
`base` package and the `data.json`.
